# Future Vision

## Purpose
Translate the PRD's long-term product vision into roadmap, architecture, and executive narrative.

Use this skill for:
- intent-centric enterprise control
- app-centric to action-centric transformation
- Dataverse as semantic enterprise graph
- Dataverse as AI operating system
- Dataverse as enterprise memory layer
- long-term roadmap framing

## V1 Boundary
This skill produces future-state strategy and roadmap guidance only. It does not assert that the future-state runtime exists today.

## Workflow
1. Frame the current state as app-centric navigation, forms, and manual table work.
2. Frame the target state as intent-centric enterprise control through natural language, orchestration, memory, and governance.
3. Describe Dataverse's future role as semantic graph, action runtime substrate, and memory layer.
4. Split the roadmap into credible phases: guidance plugin, action design system, connected runtime, governed execution, proactive intelligence, and marketplace ecosystem.
5. Identify proof points needed before external product claims: tenant integrations, policy enforcement, audit trails, reliability, and user adoption.

## Output Format
Return:
- `Vision statement`: concise future-state description.
- `Transformation narrative`: from app-centric to intent-centric operation.
- `Platform thesis`: Dataverse as graph, operating system, and memory layer.
- `Roadmap phases`: practical evolution path.
- `Proof points`: evidence needed for credible enterprise adoption.
