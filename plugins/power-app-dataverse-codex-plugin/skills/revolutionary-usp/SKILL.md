# Revolutionary USP

## Purpose
Create sharp positioning for the product's core claim: "Conversational Enterprise Execution Platform" for Dataverse and Power Apps.

Use this skill for:
- plugin marketplace descriptions
- PRD refinement
- executive pitch copy
- sales narrative
- homepage or internal launch messaging
- feature-to-value translation

## V1 Boundary
This skill produces positioning and messaging guidance only. It must not overstate v1 as a live autonomous execution runtime.

## Workflow
1. Start with the negative positioning: this is not merely "AI for Power Apps".
2. State the positive positioning: conversational enterprise execution over Dataverse and Power Platform.
3. Explain the abstraction: UI, processes, systems, and data models become intent, language, orchestration, and governed action.
4. Separate current plugin capability from future runtime vision.
5. Produce enterprise-practical wording that can be used in manifests, decks, PRDs, and stakeholder messages.

## Output Format
Return:
- `One-line USP`: crisp positioning sentence.
- `Not this / but this`: contrast against weaker positioning.
- `Abstraction model`: what gets hidden and what replaces it.
- `Current vs future`: honest boundary between v1 and runtime vision.
- `Recommended copy`: short, medium, and executive versions.
